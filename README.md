# Aman Raj — personal site

Upload everything in this folder to the root of your GitHub Pages repo
(replace the old files), keeping the `resume/` folder.

## Add booking links later
Open `index.html`, search for `EDIT HERE`, and paste your links:

    var BOOKING = {
      intro:   "https://calendly.com/...",   // 20-min hiring call
      consult: "https://cal.com/...",        // 30-min survey/field ops call
      mentor:  "https://topmate.io/..."      // UPSC & career guidance
    };

Any link left as "" shows a "Copy email to schedule" button instead.

## Update the UPSC status
Search for `Mains result` in `index.html` and change "Awaited" when results are out.
